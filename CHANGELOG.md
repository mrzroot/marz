# Changelog

## 0.1.0 (2026-10-16)

First release.

- `marz scan`: offline scan of code and 12 manifest formats against a sourced knowledge base of 31 services × IR/CN/RU, with text, JSON, Markdown and SARIF output, `--fail-on`, `.marzignore` and `marz-ignore`.
- `marz probe`: step-by-step DNS/TCP/TLS/HTTP reachability test with block and geo-block fingerprints.
- `marz check` and `scan --ooni`: live OONI evidence.
- `marz fix fonts`: self-host Google Fonts.
- GitHub Action, one-line installers, and a WebAssembly build that powers the browser demo.
