Will your app make it across the border?

marz reads your code and tells you which services are blocked, sanctioned or unavailable in Iran, China and Russia: Firebase, Google Maps, reCAPTCHA, OpenAI, Stripe, YouTube and more. It cites a source for each verdict and suggests alternatives that work there.

curl -fsSL https://mrzroot.github.io/marz/install.sh | sh

Single binary, no dependencies. The installer resumes broken downloads and checks SHA-256. Then run marz in your project.

Four commands

marz

Scans code and 12 manifest formats: npm, pip, Poetry, Go, Flutter, Gradle, Maven, CocoaPods, Composer, Bundler, Dockerfiles and compose files. Output as text, JSON, Markdown or SARIF, with --fail-on for CI.

$ marz --country IR --fail-on high
CRITICAL Firebase (backend)
   IR ⊘ sanctioned
   src/firebase.ts:6 shop-demo.firebaseapp.com
   IR: → Supabase · Appwrite · Liara / ArvanCloud

marz probe

Run it from inside the country. It tests DNS, TCP, TLS and HTTP step by step and recognises the Iranian filter's 10.10.34.x DNS answers, block pages, Cloudflare 1009, CloudFront geo-blocks and the AI APIs' "unsupported country" errors.

$ marz probe --from . -v
✖ generativelanguage.googleapis.com  geo-blocked
    Google: user location is not supported
✓ api.anthropic.com  ok  (HTTP 401: wants a key)

marz check

Live evidence from OONI's measurements inside each country. Real output from 2026-10-16:

$ marz check www.youtube.com --country IR,RU
IR  blocked: 4762 measurements,
    93% anomalous, 3250 confirmed
RU  likely blocked: 49598 measurements,
    55% anomalous

marz fix fonts

The most common issue, fixed for you: it downloads the Google Fonts woff2 subsets into your web root and rewrites your <link> and @import tags.

What the statuses mean

  • blockedFiltered by the state censor.
  • sanctionedThe provider refuses users or developers from the country.
  • unavailableThe service doesn't operate or sell there.
  • degradedThrottled, slow or unreliable.
  • unknownNo reliable public data. marz says so instead of guessing; run probe.
  • okWorks, as far as public sources say.

In every pull request

The GitHub Action adds a Markdown report to the job summary, can upload SARIF to code scanning, and fails the build at the severity you choose.

- uses: mrzroot/marz@v0.1.0
  with:
    countries: IR,CN
    fail-on: high
    sarif: true
